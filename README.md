# Music Jars

Fill a jar for every band, DJ and nightclub you love, with blood, tips or goo, until it overflows. Then save your shelf as a picture.

Live at https://popantipop.github.io/music-jars/

A single static page (`index.html`). There's no build step and no backend, and ratings stay in each visitor's browser. To change a shelf, edit the `DECKS` object in `index.html`.

After [Kink Jars](https://lockedtony.github.io/kink-jars/).
